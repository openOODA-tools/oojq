# Corpus-blind differential probes for `make sweep`.
#
# Nothing here is in the Makefile parity corpus. That is the point: the parity
# corpus only grows where a divergence was already found, so it confirms and
# never discovers. These lines are here to be wrong about something new.
#
# One filter per line. Blank lines and lines starting with # are skipped.
# A line is compared byte for byte against jq in all three output modes.
# Expected values for any regression test taken from a divergence here must be
# taken from jq by running the identical pipeline, never by hand.
#
# Two of these found real bugs on the day they were written:
#   [(0*-1),(0)]|max          max compared with > so it kept the earlier -0
#   if .a>1 then .a else 0 end  the branch read the true, not the value
#
# The object construction lines at the end were added after that feature landed,
# and they are here for the class rather than the cases: a key written twice, a
# generator on either side, an entry that answers nothing, and a key that is an
# expression. That class could not be written down at all until {a: 1} existed,
# which is the argument for keeping a corpus that can carry a new shape.
#
# The with_entries lines came next, for the same reason: with_entries is a
# rewrite, so what is worth probing is the shape of its body, not the rewrite.
# The setpath lines at the end came last, and they are here for the class that
# only setpath can be wrong about: a path that walks into a value it had to grow,
# a value that answers nothing, a generator on either side, and the refusals. That
# class is what the create-an-intermediate crash lived in, and every one of its
# members was byte identical to jq the day before the crash was found.
# The scalar refusal lines came after that. This build used to say "cannot index
# a int with \"b\"" and "cannot iterate over a int", both of which are sentences
# jq never writes and neither of which a reader could have compared against
# anything. The class here is every kind a scalar can be, against both an index
# and an iterate, because the two sentences name the kind differently.
